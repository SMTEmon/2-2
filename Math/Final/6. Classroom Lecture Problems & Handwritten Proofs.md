## 1. Bivariate Joint PDF: Classroom Worked Problem (PDF 2)

**Problem Statement:**
Consider the continuous joint probability density function (PDF) of $X$ and $Y$:

$$f(x, y) = \begin{cases} \frac{6}{5}(x^2 + 2xy), & 0 \le x \le 1, \, 0 \le y \le 1 \\ 0, & \text{otherwise} \end{cases}$$

Compute:
1. Marginal density functions $f_1(x) = g(x)$ and $f_2(y) = h(y)$
2. Expected values $\mu_X = E[X]$, $\mu_Y = E[Y]$, and $E[XY]$
3. Covariance $\text{Cov}(X, Y)$
4. Variances $V[X]$ and $V[Y]$
5. Correlation coefficient $\rho(X, Y)$

> [!note]- View Complete Step-by-Step Solution
> 
> ### Step 1: Marginal Density Functions
> 
> #### Marginal PDF of $X$: $f_1(x) = g(x)$
> $$g(x) = \int_{0}^{1} \frac{6}{5}(x^2 + 2xy) \, dy = \frac{6}{5} \left[ x^2 y + xy^2 \right]_{0}^{1} = \mathbf{\frac{6}{5} x(x + 1)}, \quad 0 \le x \le 1$$
> 
> #### Marginal PDF of $Y$: $f_2(y) = h(y)$
> $$h(y) = \int_{0}^{1} \frac{6}{5}(x^2 + 2xy) \, dx = \frac{6}{5} \left[ \frac{x^3}{3} + x^2 y \right]_{0}^{1} = \frac{6}{5} \left( \frac{1}{3} + y \right) = \mathbf{\frac{2}{5}(1 + 3y)}, \quad 0 \le y \le 1$$
> 
> ---
> 
> ### Step 2: Means & Expectations
> 
> #### Expectation $E[X]$:
> $$\mu_X = E[X] = \int_{0}^{1} x \cdot \frac{6}{5}x(x+1) \, dx = \frac{6}{5} \int_{0}^{1} (x^3 + x^2) \, dx = \frac{6}{5} \left[ \frac{x^4}{4} + \frac{x^3}{3} \right]_{0}^{1}$$
> $$\mu_X = \frac{6}{5} \left( \frac{1}{4} + \frac{1}{3} \right) = \frac{6}{5} \left( \frac{7}{12} \right) = \mathbf{\frac{7}{10} = 0.7}$$
> 
> #### Expectation $E[Y]$:
> $$\mu_Y = E[Y] = \int_{0}^{1} y \cdot \frac{2}{5}(1+3y) \, dy = \frac{2}{5} \int_{0}^{1} (y + 3y^2) \, dy = \frac{2}{5} \left[ \frac{y^2}{2} + y^3 \right]_{0}^{1}$$
> $$\mu_Y = \frac{2}{5} \left( \frac{1}{2} + 1 \right) = \frac{2}{5} \left( \frac{3}{2} \right) = \mathbf{\frac{3}{5} = 0.6}$$
> 
> #### Joint Expectation $E[XY]$:
> $$E[XY] = \int_{0}^{1} \int_{0}^{1} xy \cdot \frac{6}{5}(x^2 + 2xy) \, dx \, dy = \frac{6}{5} \int_{0}^{1} \int_{0}^{1} (x^3 y + 2x^2 y^2) \, dx \, dy$$
> Inner integral w.r.t $x$: $\int_0^1 (x^3 y + 2x^2 y^2) dx = \left[ \frac{x^4 y}{4} + \frac{2x^3 y^2}{3} \right]_0^1 = \frac{y}{4} + \frac{2y^2}{3}$
> Outer integral w.r.t $y$: $\int_0^1 \left( \frac{y}{4} + \frac{2y^2}{3} \right) dy = \left[ \frac{y^2}{8} + \frac{2y^3}{9} \right]_0^1 = \frac{1}{8} + \frac{2}{9} = \frac{25}{72}$
> $$E[XY] = \frac{6}{5} \times \frac{25}{72} = \mathbf{\frac{5}{12}}$$
> 
> ---
> 
> ### Step 3: Covariance Calculation
> $$\text{Cov}(X, Y) = E[XY] - \mu_X \mu_Y = \frac{5}{12} - \left( \frac{7}{10} \times \frac{3}{5} \right) = \frac{5}{12} - \frac{21}{50}$$
> $$\text{Cov}(X, Y) = \frac{125 - 126}{300} = \mathbf{-\frac{1}{300}}$$
> 
> ---
> 
> ### Step 4: Variances $V[X]$ and $V[Y]$
> 
> #### Expectation $E[X^2]$:
> $$E[X^2] = \int_{0}^{1} x^2 \cdot \frac{6}{5}x(x+1) \, dx = \frac{6}{5} \int_{0}^{1} (x^4 + x^3) \, dx = \frac{6}{5} \left[ \frac{x^5}{5} + \frac{x^4}{4} \right]_{0}^{1} = \frac{6}{5} \left( \frac{9}{20} \right) = \mathbf{\frac{27}{50}}$$
> $$V[X] = E[X^2] - (E[X])^2 = \frac{27}{50} - \left( \frac{7}{10} \right)^2 = \frac{27}{50} - \frac{49}{100} = \mathbf{\frac{1}{20} = 0.05}$$
> 
> #### Expectation $E[Y^2]$:
> $$E[Y^2] = \int_{0}^{1} y^2 \cdot \frac{2}{5}(1+3y) \, dy = \frac{2}{5} \int_{0}^{1} (y^2 + 3y^3) \, dy = \frac{2}{5} \left[ \frac{y^3}{3} + \frac{3y^4}{4} \right]_{0}^{1} = \frac{2}{5} \left( \frac{13}{12} \right) = \mathbf{\frac{13}{20}}$$
> $$V[Y] = E[Y^2] - (E[Y])^2 = \frac{13}{20} - \left( \frac{3}{5} \right)^2 = \frac{13}{20} - \frac{9}{25} = \mathbf{\frac{11}{150}} \approx 0.0733$$
> 
> ---
> 
> ### Step 5: Correlation Coefficient $\rho(X, Y)$
> $$\rho(X, Y) = \frac{\text{Cov}(X, Y)}{\sqrt{V[X] \cdot V[Y]}} = \frac{-1/300}{\sqrt{\left( \frac{1}{20} \right) \left( \frac{11}{150} \right)}} = \frac{-1/300}{\sqrt{\frac{11}{3000}}} = \mathbf{-0.055}$$
> 
> **Conclusion:** The random variables $X$ and $Y$ are **negatively correlated**.

## 2. Classroom Normal Curve Central Area Problem (PDF 1)

**Problem Statement:**
In a normal distribution with mean $\mu = 50$ and variance $\sigma^2 = 100$ (so $\sigma = 10$), find the values of $X$ that cover the **central 50%** of the area under the curve using exact classroom $Z$-table values.

> [!note]- View Classroom Solution
> We look for $K$ such that $P(-K < Z < K) = 0.50$.
> By symmetry:
> $$2 P(Z < K) = 0.50 \implies P(Z < K) = 0.25$$
> 
> From the classroom table lookup, $P(Z < -0.675) = 0.25 \implies K = 0.675$.
> 
> Transforming back to $X = \mu \pm K\sigma$:
> - $x_1 = 50 - (0.675 \times 10) = 50 - 6.75 = \mathbf{43.25}$
> - $x_2 = 50 + (0.675 \times 10) = 50 + 6.75 = \mathbf{56.75}$
> 
> **Answer:** The central 50% of the area is contained in the interval **$(43.25, 56.75)$**.

## 3. General Variance of Sum Theorem Proof (PDF 2)

**Theorem:** For any set of random variables $X_1, X_2, \dots, X_n$:

$$\text{Var}\left(\sum_{i=1}^{n} X_i\right) = \sum_{i=1}^{n} \text{Var}(X_i) + 2 \sum_{1 \le i < j \le n} \text{Cov}(X_i, X_j)$$

> [!note]- View Proof
> Using the property that $\text{Var}(U) = \text{Cov}(U, U)$:
> 
> $$\text{Var}\left(\sum_{i=1}^{n} X_i\right) = \text{Cov}\left(\sum_{i=1}^{n} X_i, \, \sum_{j=1}^{n} X_j\right) = \sum_{i=1}^{n} \sum_{j=1}^{n} \text{Cov}(X_i, X_j)$$
> 
> Separate the diagonal terms ($i = j$) from off-diagonal terms ($i \neq j$):
> 
> $$\text{Var}\left(\sum_{i=1}^{n} X_i\right) = \sum_{i=1}^{n} \text{Cov}(X_i, X_i) + \sum_{i \neq j} \text{Cov}(X_i, X_j)$$
> 
> Since $\text{Cov}(X_i, X_i) = \text{Var}(X_i)$ and by symmetry $\text{Cov}(X_i, X_j) = \text{Cov}(X_j, X_i)$:
> 
> $$\text{Var}\left(\sum_{i=1}^{n} X_i\right) = \sum_{i=1}^{n} \text{Var}(X_i) + 2 \sum_{1 \le i < j \le n} \text{Cov}(X_i, X_j) \quad \text{(Proved)}$$
