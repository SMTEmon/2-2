## 🧮 Problem Set 1: Multi-Hop IP Fragmentation

### Problem Statement
An IP datagram of **Total Length = 3500 bytes** (20 bytes header $+ 3480$ bytes payload) with $\text{Identification} = 421$, $\text{DF} = 0$, and $\text{MF} = 0$ is transmitted across a path:
$$\text{Host A} \xrightarrow{\text{MTU } 1500} \text{Router R1} \xrightarrow{\text{MTU } 700} \text{Router R2} \to \text{Host B}$$

**Question:** Compute all fragment parameters produced at Router R1, and then show the resulting fragments when the *second* fragment from R1 is forwarded across the $\text{MTU} = 700$ link by Router R2.

---

### Step-by-Step Solution

#### Part A: Fragmentation at Router R1 ($\text{MTU} = 1500$)
- Maximum Data Payload per fragment:
  $$\text{Max Data} = \left\lfloor \frac{1500 - 20}{8} \right\rfloor \times 8 = 1480\text{ bytes}$$
- Total data to send $= 3480\text{ bytes}$.
  - Frag 1: Data $[0 - 1479]$ ($1480\text{ bytes}$)
  - Frag 2: Data $[1480 - 2959]$ ($1480\text{ bytes}$)
  - Frag 3: Data $[2960 - 3479]$ ($520\text{ bytes}$)

**Table of Fragments generated by Router R1:**

| Fragment | Total Length | Data Bytes | Identification | MF Flag | Fragment Offset Value ($\text{Bytes}/8$) |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **Frag 1** | $1500\text{ B}$ | 1480 | 421 | **1** | $\frac{0}{8} = \mathbf{0}$ |
| **Frag 2** | $1500\text{ B}$ | 1480 | 421 | **1** | $\frac{1480}{8} = \mathbf{185}$ |
| **Frag 3** | $540\text{ B}$ | 520 | 421 | **0** | $\frac{2960}{8} = \mathbf{370}$ |

---

#### Part B: Further Fragmentation of Fragment 2 at Router R2 ($\text{MTU} = 700$)
- Fragment 2 has Total Length $= 1500\text{ B}$ (20B header $+ 1480\text{B}$ data), $\text{MF} = 1$, and $\text{Offset} = 185$.
- Maximum Data Payload for $\text{MTU} = 700$:
  $$\text{Max Data} = \left\lfloor \frac{700 - 20}{8} \right\rfloor \times 8 = \left\lfloor \frac{680}{8} \right\rfloor \times 8 = 680\text{ bytes}$$
- Partitioning the 1480 bytes of Frag 2:
  - Sub-frag 2a: $680\text{ bytes}$ (Data bytes $[1480 - 2159]$)
  - Sub-frag 2b: $680\text{ bytes}$ (Data bytes $[2160 - 2839]$)
  - Sub-frag 2c: Remaining $120\text{ bytes}$ (Data bytes $[2840 - 2959]$)

**Table of Sub-Fragments generated by Router R2 for Frag 2:**

| Sub-Fragment | Total Length | Data Bytes | Identification | MF Flag | Fragment Offset Value ($\text{Bytes}/8$) |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **Frag 2a** | $700\text{ B}$ | 680 | 421 | **1** | $\frac{1480}{8} = \mathbf{185}$ |
| **Frag 2b** | $700\text{ B}$ | 680 | 421 | **1** | $\frac{1480 + 680}{8} = \frac{2160}{8} = \mathbf{270}$ |
| **Frag 2c** | $140\text{ B}$ | 120 | 421 | **1** *(Inherits MF=1 from Frag 2!)* | $\frac{2160 + 680}{8} = \frac{2840}{8} = \mathbf{355}$ |

## 🧮 Problem Set 2: Variable-Length Subnet Masking (VLSM)

### Problem Statement
An ISP assigns the block **`198.51.100.0/24`** to a university campus. Design an optimal addressing plan satisfying the following department host requirements:
1. **Computer Science (CS):** 60 hosts
2. **Electrical Engineering (EE):** 28 hosts
3. **Administration (Admin):** 12 hosts
4. **Router-to-Router Link (R-Link):** 2 hosts

---

### Step-by-Step Solution

> [!tip] Golden VLSM Rule
> Always allocate subnets in descending order of size (largest host requirement first) to prevent fragmentation of the address block.

#### 1. CS Department (60 hosts)
- Need $N + 2 = 60 + 2 = 62$ addresses.
- Smallest power of 2: $2^6 = 64 \implies 6$ host bits.
- Subnet Prefix: $32 - 6 = \mathbf{/26}$ (Mask: `255.255.255.192`).
- Block: **`198.51.100.0/26`**
- Usable Host Range: `198.51.100.1` to `198.51.100.62`.
- Broadcast: `198.51.100.63`.

#### 2. EE Department (28 hosts)
- Need $N + 2 = 28 + 2 = 30$ addresses.
- Smallest power of 2: $2^5 = 32 \implies 5$ host bits.
- Subnet Prefix: $32 - 5 = \mathbf{/27}$ (Mask: `255.255.255.224`).
- Next available address: **`198.51.100.64/27`**
- Usable Host Range: `198.51.100.65` to `198.51.100.94`.
- Broadcast: `198.51.100.95`.

#### 3. Administration (12 hosts)
- Need $N + 2 = 12 + 2 = 14$ addresses.
- Smallest power of 2: $2^4 = 16 \implies 4$ host bits.
- Subnet Prefix: $32 - 4 = \mathbf{/28}$ (Mask: `255.255.255.240`).
- Next available address: **`198.51.100.96/28`**
- Usable Host Range: `198.51.100.97` to `198.51.100.110`.
- Broadcast: `198.51.100.111`.

#### 4. Router-to-Router Link (2 hosts)
- Need $N + 2 = 2 + 2 = 4$ addresses.
- Smallest power of 2: $2^2 = 4 \implies 2$ host bits.
- Subnet Prefix: $32 - 2 = \mathbf{/30}$ (Mask: `255.255.255.252`).
- Next available address: **`198.51.100.112/30`**
- Usable Host Range: `198.51.100.113` to `198.51.100.114`.
- Broadcast: `198.51.100.115`.

**Master Allocation Table:**

| Subnet Identifier | Allocated Prefix | Subnet Mask | Usable Host Range | Broadcast IP | Unallocated Free Space Remaining |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **CS Dept (60)** | `198.51.100.0/26` | `255.255.255.192` | `.1` – `.62` | `198.51.100.63` | — |
| **EE Dept (28)** | `198.51.100.64/27` | `255.255.255.224` | `.65` – `.94` | `198.51.100.95` | — |
| **Admin (12)** | `198.51.100.96/28` | `255.255.255.240` | `.97` – `.110` | `198.51.100.111` | — |
| **R-Link (2)** | `198.51.100.112/30` | `255.255.255.252` | `.113` – `.114` | `198.51.100.115` | `198.51.100.116/30` + `/29` + `/25` free! |

## 🧮 Problem Set 3: Weighted Fair Queuing (WFQ) Calculation

### Problem Statement
A router output port has link capacity $R = 12\text{ Mbps}$. Three traffic classes ($C_1, C_2, C_3$) have weights $w_1 = 1$, $w_2 = 2$, and $w_3 = 3$.

1. **Calculate the throughput share** for each class when all three classes have queued packets.
   $$\text{Total Weight} = 1 + 2 + 3 = 6$$
   - $C_1 \text{ Share} = 12\text{ Mbps} \times \frac{1}{6} = \mathbf{2\text{ Mbps}}$
   - $C_2 \text{ Share} = 12\text{ Mbps} \times \frac{2}{6} = \mathbf{4\text{ Mbps}}$
   - $C_3 \text{ Share} = 12\text{ Mbps} \times \frac{3}{6} = \mathbf{6\text{ Mbps}}$

2. **Dynamic Adaptation:** If Class 3 empties its queue, calculate the new throughput shares for $C_1$ and $C_2$.
   $$\text{New Active Weight} = 1 + 2 = 3$$
   - $C_1 \text{ Share} = 12\text{ Mbps} \times \frac{1}{3} = \mathbf{4\text{ Mbps}}$
   - $C_2 \text{ Share} = 12\text{ Mbps} \times \frac{2}{3} = \mathbf{8\text{ Mbps}}$
